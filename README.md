# MoveYourAssets 🏃‍♂️🚴‍♂️🚶‍♂️

Outdoor activity tracker for iOS.
Track your runs, walks, and rides — offline, private, simple.

## Features

- GPS tracking (running, walking, cycling)
- Real-time pace, distance, time
- Weather forecast (4-hour ahead)
- Apple Health integration (import & export)
- Dashboard with customizable cards
- Voice announcements during workouts
- Auto-pause detection
- Dark mode support
- Polish & English localization
- 100% offline — no account required
