# Changelog

All notable changes to MoveYourAssets will be documented here.

## [1.0.0] - Coming Soon

### Features
- GPS tracking for running, walking, and cycling
- Real-time metrics: distance, time, pace
- 4-hour weather forecast (Open-Meteo)
- Apple Health integration (import workouts, heart rate, export)
- Customizable Dashboard with reorderable cards
- Quick Start from Dashboard
- Workout history with detail view
- Statistics overview
- Voice announcements (distance & time updates)
- Auto-pause detection
- Dark/Light/Auto theme
- Keep screen on (app-wide or workout only)
- Live Activity on lock screen
- Polish & English localization
- 100% offline — no account, no cloud

### Known Limitations
- Data export (planned for v2.0 PRO)
- Advanced statistics & charts (planned for v2.0 PRO)
- Weekly goals (planned for v2.0)
- Lap detection (planned for v2.0)
- Map view (planned for future release)
